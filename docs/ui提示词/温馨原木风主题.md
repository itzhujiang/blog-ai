# 温馨原木风个人博客UI设计提示词

## 整体主题设计提示词

### **核心视觉概念**
"一个充满自然温暖的个人博客空间，如同走进一家MUJI无印良品店铺，整体氛围安静舒适，散发着原木的自然质感。"

### **色彩系统提示词**
"主色调采用温暖的米白色背景 (#F8F6F2)，搭配浅原木色 (#D4A574) 作为主要强调色，深棕色 (#8B6F47) 用于文字和重要元素。点缀色使用橄榄绿 (#7A8B6E)，给空间增添一抹自然的清新感。"

### **材质和纹理提示词**
"界面背景使用非常淡雅的木纹纹理，若有若无。所有交互元素带有轻微的木质边缘效果，边角圆润处理，避免任何尖锐的视觉元素。整体材质感觉温润如玉。"

### **光影氛围提示词**
"整体光线模拟午后三点的温暖阳光，柔和而不刺眼。内容区域有轻微的自然阴影，如同阳光透过百叶窗的投影。所有元素的光影效果都要保持克制和温柔。"

### **字体和排版提示词**
"选用圆润饱满的无衬线字体，字符间距略宽，给人亲切感。标题使用深棕色，正文保持深灰棕色，确保良好的可读性。整体排版留白充足，不拥挤。"

### **装饰元素提示词**
"可以使用简约的植物叶子轮廓、极简的几何图形作为装饰。所有装饰元素都要保持克制，不能喧宾夺主。适当使用一些原木色调的色块分割空间。"

## 色彩规范

### 主色调
- 背景色: #F8F6F2 (温暖米白色)
- 强调色: #D4A574 (浅原木色)
- 文字色: #8B6F47 (深棕色)

### 辅助色
- 点缀色: #7A8B6E (橄榄绿)
- 浅色背景: #FAFAF8 (更浅的米白)
- 深色文字: #5C4A3C (更深棕色)

## 设计原则
1. **温暖感优先** - 所有视觉元素都要传递温暖舒适的感觉
2. **自然质感** - 保持原木的天然纹理和温润触感
3. **简约克制** - 装饰元素适度，避免过度设计
4. **留白充足** - 给用户舒适的阅读空间
5. **圆角处理** - 所有边角都要圆润，避免尖锐感

## 氛围营造
- 想象午后阳光透过百叶窗洒进木屋的感觉
- 类似MUJI店铺的极简自然美学
- 整体要让人感到放松、安心、舒适
