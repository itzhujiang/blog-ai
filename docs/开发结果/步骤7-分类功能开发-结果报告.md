## 三、架构说明

### 3.1 文章数量统计 SQL

所有位置使用统一的 `Sequelize.literal` 子查询：

```sql
SELECT COUNT(*)
FROM article_categories ac
JOIN articles a ON ac.article_id = a.id
WHERE ac.category_id = "Category".id
  AND a.status = 'published'
  AND a.deleted_at IS NULL
```

### 3.2 数据流转

```
服务端页面渲染（ISR）:
  数据库 → getCategories()（含子查询） → CategoryFilter 组件
  数据库 → getCategories()（含子查询） → CategoryNav 首页组件

客户端 API 调用（未来场景）:
  客户端 → GET /api/categories → NextResponse.json → 客户端组件

动态 SEO:
  searchParams.category → 查询分类名 → generateMetadata → <title>
```

### 3.3 关键技术实现

- **文章数量子查询**：`Sequelize.literal` 在 `attributes` 中添加 COUNT 子查询
- **动态 SEO**：`generateMetadata` 根据 `category` URL 参数查询分类名，生成动态 title/description
- **类型兼容**：`articleCount` 设为可选字段，不影响已有组件（如文章详情页的分类标签）
- **API 缓存**：`Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400`
