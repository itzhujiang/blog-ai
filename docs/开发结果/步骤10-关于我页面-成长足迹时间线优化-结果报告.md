## 三、具体改动

### 3.1 移除 `getNodeSize()` 函数

**旧设计**：根据索引返回递减尺寸（h-12 → h-8 → h-7 → h-5），圆圈内显示年份后两位（如 `24`）。

**问题**：
- 仅显示年份后两位，日期信息不完整
- 节点尺寸递减导致视觉不一致

### 3.2 新增 `formatDate()` 函数

```typescript
function formatDate(timestamp: number): string {
  const date = new Date(timestamp);
  const y = date.getFullYear();
  const m = String(date.getMonth() + 1).padStart(2, '0');
  const d = String(date.getDate()).padStart(2, '0');
  return `${y}.${m}.${d}`;
}
```

输出格式：`2024.01.01`、`2016.07.01` 等完整年月日。

### 3.3 统一节点设计

| 属性 | 旧值 | 新值 |
|------|------|------|
| 节点尺寸 | h-12/h-8/h-7/h-5（递减） | h-3 w-3（统一） |
| 节点内容 | 年份后两位文字 | 无文字，纯实心圆点 |
| 节点颜色 | bg-wood-light | bg-primary |
| 日期显示 | 圆圈内 | 独立标签，位于节点上方 |
| 条目间距 | mb-12 / 无（不一致） | mb-10（统一，末项无间距） |

### 3.4 滚动容器

- `<h2>` 标题放在滚动容器**外部**，始终可见
- 滚动区域：`max-h-[600px] overflow-y-auto scrollbar-hide`
