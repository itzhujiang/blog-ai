## 六、开发过程中的问题与解决

### 6.1 缺少类型定义

**问题**：TypeScript 编译报错，缺少 `@types/cls-hooked`

**解决**：
```bash
npm install -D @types/cls-hooked
```

### 6.2 ESLint import/order 错误

**问题**：ESLint 报告 import 语句顺序错误，要求外部依赖和本地导入之间有空行

**解决**：在所有模型文件中，在外部依赖导入和本地模块导入之间添加空行

### 6.3 ESLint react-hooks/rules-of-hooks 错误

**问题**：`Sequelize.useCLS()` 被误判为 React Hook 调用

**解决**：在 `db.ts` 中添加 eslint-disable 注释：
```typescript
// eslint-disable-next-line react-hooks/rules-of-hooks
Sequelize.useCLS(namespace);
```

### 6.4 ESLint no-unused-vars 错误

**问题**：枚举成员被报告为未使用变量

**解决**：修改 `eslint.config.mjs`，为 `**/enums.ts` 文件添加特殊规则：
```javascript
{
  files: ['**/enums.ts'],
  rules: {
    'no-unused-vars': 'off',
  },
},
```
