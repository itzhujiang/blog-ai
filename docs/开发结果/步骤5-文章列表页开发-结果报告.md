## 三、架构说明

### 3.1 数据获取流程

```
URL 参数（page, category, sort）
  → ArticlesPage 服务端组件解析参数
  → Promise.all([getArticles(), getCategories()])
  → Sequelize 查询（含 include 关联、子查询、分页）
  → 数据序列化（BIGINT → parseInt）
  → 子组件 Props 传递
  → ISR 缓存（revalidate: 3600）
```

### 3.2 组件架构

```
ArticlesPage (服务端组件)
  ├── CategoryFilter (客户端组件 - 'use client')
  ├── SortOptions (客户端组件 - 'use client')
  ├── ArticleCard[] (服务端组件)
  └── Pagination (服务端组件 - next/link)
```

### 3.3 关键技术实现

- **评论数子查询**：使用 `Sequelize.literal` 在 attributes 中添加 SQL 子查询
- **分类筛选**：通过 `include` 的 `required: true` + `where` 条件实现
- **分页**：`findAndCountAll` + `distinct: true` + `subQuery: false`
- **URL 参数管理**：客户端组件使用 `useRouter` + `useSearchParams`
