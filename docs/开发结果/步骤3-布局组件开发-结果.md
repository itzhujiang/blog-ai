## 四、技术实现要点

### 4.1 响应式设计

- Navigation 使用 `hidden md:flex` 实现移动端隐藏
- Footer 使用 `grid-cols-1 md:grid-cols-2` 实现响应式布局

### 4.2 主题支持

所有组件使用 Tailwind CSS 的 dark 变体支持暗色模式：
- 文字颜色：`text-text-light dark:text-text-dark`
- 链接悬停：`hover:text-cta-light dark:hover:text-cta-dark`
- Logo 颜色：`text-cta-light dark:text-cta-dark`

### 4.3 客户端组件

Navigation 组件使用 `'use client'` 指令，因为需要使用 `usePathname` Hook 获取当前路径。
