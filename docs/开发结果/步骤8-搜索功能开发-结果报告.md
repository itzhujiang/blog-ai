## 三、架构说明

### 3.1 搜索查询 SQL

使用 Sequelize `Op.iLike` 对标题和摘要进行模糊匹配：

```sql
WHERE status = 'published'
  AND (title ILIKE '%关键词%' OR excerpt ILIKE '%关键词%')
```

SQL 通配符（`%`、`_`、`\`）通过 `escapeLikePattern()` 函数转义，防止注入。

### 3.2 数据流转

```
Header 搜索栏:
  用户输入 → <form action="/search"> → GET /search?q=关键词

搜索结果页（服务端渲染）:
  searchParams.q → searchArticles() → 数据库 ILIKE 查询 → SearchResultCard 列表

搜索 API（供外部调用）:
  GET /api/search?q=关键词&page=1&sort=relevance → NextResponse.json

搜索日志:
  每次搜索 → SearchLog.create() → fire-and-forget（.catch 静默处理）

排序切换:
  Link 组件 → /search?q=关键词&sort=latest → 服务端重新渲染（无客户端 JS）
```

### 3.3 关键技术实现

- **ILIKE 模糊匹配**：`Op.iLike` 匹配 title 和 excerpt，大小写不敏感
- **SQL 通配符转义**：`escapeLikePattern()` 防止 `%`、`_` 注入
- **关键词高亮**：`highlightKeyword()` 使用正则 split + `<mark>` 标签
- **搜索日志**：fire-and-forget 模式，不阻塞响应
- **排序**：Link 实现，无需客户端 JS，relevance/latest 按 publishedAt DESC，comments 按 commentCount DESC
- **渐进增强**：HeaderSearchBar 使用原生 `<form action="/search" method="get">`，无 JS 也可工作
- **force-dynamic**：搜索页禁用缓存，确保实时结果
