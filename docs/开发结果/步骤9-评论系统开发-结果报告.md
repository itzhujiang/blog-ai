## 三、架构说明

### 3.1 API 设计

**GET /api/comments?articleId=N**
- 查询 `status='approved'` 的评论，按 `createdAt ASC` 排序
- 从 SiteSetting 表读取 `author_name` 判断 `isAuthor` 标记
- 返回扁平列表 `{ comments, total }`，前端构建嵌套树
- 响应头 `Cache-Control: no-store`

**POST /api/comments**
- Body：`articleId`、`authorName`（trim, max 100）、`content`（trim, max 2000）必填，`parentId` 可选
- 记录 IP（`x-forwarded-for` / `x-real-ip`）
- 创建 `status: 'pending'`（待审核）
- 返回 201 + `{ message, comment: { id, authorName, content, createdAt, status } }`

### 3.2 数据流转

```
评论加载（CSR）:
  CommentSection useEffect → fetch GET /api/comments?articleId=N
  → 扁平列表 → buildCommentTree() → 嵌套树 → CommentItem 递归渲染

发表评论:
  CommentForm → POST /api/comments → 201 → 显示"评论已提交，等待审核"
  → onSubmitSuccess → fetchComments() 刷新列表

回复评论:
  CommentItem 回复按钮 → setReplyingTo(commentId)
  → CommentForm(isReply, parentId) → POST → 同上
```

### 3.3 关键技术实现

- **CSR 不影响 ISR**：CommentSection 为 `'use client'` 组件，评论数据通过 fetch 加载，不影响文章页 ISR 缓存
- **扁平→树转换**：`buildCommentTree()` 使用 Map 一次遍历构建嵌套结构
- **首字母头像**：取名字首字符（中文第一字 / 英文首字母大写），charCode hash 从 8 色色板选色
- **相对时间**：`formatRelativeTime()` 支持刚刚/分钟/小时/天/月/年
- **嵌套深度限制**：`depth < 2` 时递归渲染回复，防止无限嵌套
- **作者徽章**：通过 SiteSetting 表的 `author_name` 配置判断 `isAuthor`
- **IP 记录**：POST 时记录 `x-forwarded-for` 或 `x-real-ip`，用于防垃圾评论
