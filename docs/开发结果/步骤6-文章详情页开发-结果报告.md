## 三、架构说明

### 3.1 数据获取流程

```
URL /articles/[slug]
  → ArticlePage 服务端组件解析 slug
  → Sequelize 查询文章元数据（include 分类、媒体）
  → Axios 获取 Markdown 文件内容（通过 file-url 工具转换路径）
  → 数据序列化（BIGINT 转换、URL 处理）
  → 传递给子组件
  → ArticleContent 客户端渲染 Markdown
  → ISR 缓存（revalidate: 3600）
```

### 3.2 组件架构

```
ArticlePage (服务端组件)
  ├── Breadcrumb (服务端组件)
  ├── ArticleHeader (服务端组件)
  │   └── next/image (头图)
  ├── ArticleContent (客户端组件 - 'use client')
  │   ├── react-markdown
  │   ├── remark-gfm
  │   ├── rehype-highlight
  │   └── CodeBlock (复制按钮)
  ├── ArticleFooter (服务端组件)
  │   ├── 分类标签链接
  │   └── 社交分享按钮
  └── BackToTop (客户端组件 - 'use client')
```

### 3.3 关键技术实现

- **动态 SEO**：`generateMetadata` 函数根据文章标题和摘要生成 title/description/OpenGraph
- **Markdown 渲染**：`react-markdown` + `remark-gfm` + `rehype-highlight` 组合
- **代码复制**：自定义 `pre` 组件，使用 `navigator.clipboard.writeText`
- **文件 URL 转换**：`getArticleFileUrl()` 将数据库 `filePath` 转为后端完整 URL
- **404 处理**：文章不存在时调用 `notFound()`
