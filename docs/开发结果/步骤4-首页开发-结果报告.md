## 三、架构说明

### 3.1 API 调用流程

```
页面组件
    ↓ (axios)
API Route (/api/site-config)
    ↓ (Sequelize)
数据库 (site_settings 表)
    ↓
返回配置数据
```

### 3.2 Axios 使用场景

- **前端组件**：客户端组件中的 API 调用
- **服务端渲染**：页面组件中的数据获取
- **API Routes**：API 接口中的外部请求
