**分页导航**：
- 居中显示，圆形按钮

### 2.3 业务规则

- 每页显示 6 篇文章（纵向列表布局）
- 文章默认按发布时间倒序排列
- 支持按「评论最多」排序
- 分类筛选通过 URL 参数传递：`?category={slug}`
- 排序通过 URL 参数传递：`?sort=latest` 或 `?sort=comments`
- 分页通过 URL 参数传递：`?page={number}`
- 仅显示状态为 `published` 的文章
- 文章列表页使用 ISR 策略，revalidate: 3600（1小时）

### 3.4 数据获取

文章列表页使用 ISR 策略获取数据：

```typescript
// app/articles/page.tsx
export const revalidate = 3600; // 1小时重新验证

const PAGE_SIZE = 6;

async function getArticles(params: {
  page: number;
  category?: string;
  sort: SortType;
}) {
  const { Article, ArticleCategory, Category, ArticleMedia, MediaFile }
    = await initAllModels();

  const where: Record<string, unknown> = { status: 'published' };

  // 分类筛选：通过 include 的 where 条件过滤
  const include = [
    {
      model: ArticleMedia,
      where: { usageType: 'thumbnail' },
      include: [{ model: MediaFile, as: 'media', attributes: ['fileUrl'] }],
      required: false,
      limit: 1,
    },
    {
      model: ArticleCategory,
      include: [{
        model: Category,
        as: 'category',
        attributes: ['id', 'name', 'slug'],
        ...(params.category ? { where: { slug: params.category } } : {}),
      }],
      required: !!params.category,
    },
  ];

  // 排序
  const order = params.sort === 'comments'
    ? [[sequelize.literal('comment_count'), 'DESC']]
    : [['publishedAt', 'DESC']];

  const { rows, count } = await Article.findAndCountAll({
    where,
    include,
    order,
    limit: PAGE_SIZE,
    offset: (params.page - 1) * PAGE_SIZE,
    distinct: true,
    // 评论数子查询（用于排序和展示）
    attributes: {
      include: [
        [sequelize.literal(
          '(SELECT COUNT(*) FROM comments WHERE comments.article_id = "Article".id AND comments.status = \'approved\')'
        ), 'commentCount'],
      ],
    },
  });

  return {
    articles: rows,
    totalCount: count,
    totalPages: Math.ceil(count / PAGE_SIZE),
  };
}

async function getCategories() {
  const { Category } = await initAllModels();
  return Category.findAll({
    order: [['name', 'ASC']],
  });
}
```

### 3.5 数据流转

```
URL 参数（page, category, sort）

  → Sequelize 查询（带筛选、排序、分页）
  → 数据序列化（处理 BIGINT 字符串转换）
```

## 五、注意事项

### 5.1 边界情况

- **无文章数据**：显示「暂无文章」友好提示
- **无匹配分类**：显示「该分类下暂无文章」提示
- **图片加载失败**：显示占位图或默认图片
- **长标题截断**：标题不截断，摘要使用 `line-clamp-2` 限制行数
- **单页数据**：总页数为 1 时隐藏分页导航
- **无效页码**：超出范围的页码重定向到第 1 页

### 5.2 异常处理

- **数据库查询失败**：记录错误日志，显示友好错误提示
- **图片 URL 无效**：使用默认占位图
- **URL 参数非法**：使用默认值（page=1, sort=latest）

### 5.3 兼容性

- **浏览器支持**：Chrome、Firefox、Safari、Edge 最新版本
- **设备支持**：桌面端（1920x1080+）优先，移动端基本适配

### 5.4 性能考虑

- 文章列表页使用 ISR 缓存，减少数据库查询
- 图片使用 `next/image` 自动优化和懒加载
- 分类筛选和排序为客户端组件，仅交互部分使用 `'use client'`
- 评论数通过子查询获取，避免 N+1 查询问题
- 分页使用 `LIMIT/OFFSET`，配合 `findAndCountAll` 获取总数
