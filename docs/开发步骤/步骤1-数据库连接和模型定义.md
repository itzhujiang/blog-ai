## 二、需求说明

### 2.1 功能要求

- 配置 PostgreSQL 数据库连接，使用 Sequelize ORM
- 配置连接池参数，适应 2G 内存服务器限制
- 定义所有数据库模型，与数据库表结构对应
- 建立模型之间的关联关系
- 支持 TypeScript 类型定义
- 配置 log4js 日志系统

### 2.2 业务规则

- 连接池最大连接数限制为 3（适应 2G 内存）
- 所有时间字段使用毫秒级 Unix 时间戳（BIGINT）
- 支持软删除（deleted_at 字段）
- 模型定义必须与数据库表设计文档保持一致
- 使用 underscored: true 将驼峰命名转换为下划线命名

### 3.3 实现要点

#### 1. 数据库连接配置

参考 `blog-backend/server/src/models/db.ts`，配置 Sequelize 连接：

```typescript
// app/utils/models/db.ts
import cls from 'cls-hooked';
import { Sequelize, type Dialect } from 'sequelize';
import { dbLogger } from '../logger';

const namespace = cls.createNamespace('blog-ai');
Sequelize.useCLS(namespace);

export const sequelize = new Sequelize(
  process.env.DB_NAME!,
  process.env.DB_USER!,
  process.env.DB_PASSWORD!,
  {
    host: process.env.DB_HOST!,
    port: parseInt(process.env.DB_PORT || '5432'),
    dialect: 'postgres' as Dialect,
    logging: msg => dbLogger.debug(msg),
    pool: {
      max: 3,        // 最大连接数（2G内存限制）
      min: 0,
      idle: 10000,
      acquire: 30000,
    },
  }
);
```

#### 4. 模型定义示例（Article）

参考 `blog-backend/server/src/models/article.ts`，每个模型包含：
- 属性接口
- 创建属性类型
- 模型类
- 初始化函数

```typescript
// app/utils/models/article.ts
import { Model, DataTypes, Optional, Association, Sequelize } from 'sequelize';
import { ArticleCategory } from './article-category';
import { ArticleMedia } from './article-media';
import { Comment } from './comment';
import { ArticleStatusLiteral } from './enums';

// 文章属性接口
export interface ArticleAttributes {
  id: number;
  title: string;
  slug: string;
  filePath: string;
  excerpt?: string | null;
  thumbnailUrl?: string | null;
  authorName: string;
  readingTime: number;
  viewCount: number;
  status: ArticleStatusLiteral;
  publishedAt?: number | null;
  createdAt?: number | null;
  updatedAt?: number | null;
  deletedAt?: number | null;
}

// 创建时可选字段
export type ArticleCreationAttributes = Optional<
  ArticleAttributes,
  | 'id'
  | 'excerpt'
  | 'thumbnailUrl'
  | 'readingTime'
  | 'viewCount'
  | 'status'
  | 'publishedAt'
  | 'createdAt'
  | 'updatedAt'
  | 'deletedAt'
>;

// 模型类
export class Article
  extends Model<ArticleAttributes, ArticleCreationAttributes>
  implements ArticleAttributes
{
  declare id: number;
  declare title: string;
  declare slug: string;
  declare filePath: string;
  declare excerpt: string | null;
  declare thumbnailUrl: string | null;
  declare authorName: string;
  declare readingTime: number;
  declare viewCount: number;
  declare status: ArticleStatusLiteral;
  declare publishedAt: number | null;
  declare createdAt: number | null;
  declare updatedAt: number | null;
  declare deletedAt: number | null;

  declare static associations: {
    categories: Association<Article, ArticleCategory>;
    media: Association<Article, ArticleMedia>;
    comments: Association<Article, Comment>;
  };
}

// 初始化函数
export function initArticleModel(sequelize: Sequelize): typeof Article {
  Article.init(
    {
      id: {
        type: DataTypes.INTEGER,
        autoIncrement: true,
        primaryKey: true,
        comment: '文章ID',
      },
      title: {
        type: DataTypes.STRING(255),
        allowNull: false,
        comment: '文章标题',
      },
      slug: {
        type: DataTypes.STRING(255),
        allowNull: false,
        unique: true,
        comment: 'URL友好标识',
      },
      filePath: {
        type: DataTypes.STRING(500),
        allowNull: false,
        comment: '服务端文件路径',
      },
      excerpt: {
        type: DataTypes.TEXT,
        allowNull: true,
        comment: '文章摘要',
      },
      thumbnailUrl: {
        type: DataTypes.STRING(500),
        allowNull: true,
        comment: '列表缩略图URL',
      },
      authorName: {
        type: DataTypes.STRING(100),
        allowNull: false,
        defaultValue: '木心',
        comment: '作者名',
      },
      readingTime: {
        type: DataTypes.INTEGER,
        allowNull: false,
        defaultValue: 0,
        comment: '预计阅读时间(分钟)',
      },
      viewCount: {
        type: DataTypes.INTEGER,
        allowNull: false,
        defaultValue: 0,
        comment: '浏览次数',
      },
      status: {
        type: DataTypes.ENUM('draft', 'published', 'archived'),
        allowNull: false,
        defaultValue: 'published',
        comment: '发布状态',
      },
      publishedAt: {
        type: DataTypes.BIGINT,
        allowNull: true,
        comment: '发布时间（毫秒级Unix时间戳）',
      },
      createdAt: {
        type: DataTypes.BIGINT,
        allowNull: false,
        defaultValue: () => Date.now(),
        comment: '创建时间（毫秒级Unix时间戳）',
      },
      updatedAt: {
        type: DataTypes.BIGINT,
        allowNull: false,
        defaultValue: () => Date.now(),
        comment: '更新时间（毫秒级Unix时间戳）',
      },
      deletedAt: {
        type: DataTypes.BIGINT,
        allowNull: true,
        comment: '删除时间（软删除）',
      },
    },
    {
      sequelize,
      tableName: 'articles',
      underscored: true,
      timestamps: false,
      paranoid: true,
      deletedAt: 'deleted_at',
      hooks: {
        beforeCreate: (instance: Article) => {
          const now = Date.now();
          instance.createdAt = now;
          instance.updatedAt = now;
          if (instance.status === 'published' && !instance.publishedAt) {
            instance.publishedAt = now;
          }
        },
        beforeUpdate: (instance: Article) => {
          instance.updatedAt = Date.now();
        },
      },
      indexes: [
        { fields: ['status', 'published_at'] },
        { unique: true, fields: ['slug'] },
        { fields: ['author_name'] },
        { fields: ['created_at'] },
      ],
      comment: '文章主表',
    }
  );

  return Article;
}
```

## 五、注意事项

### 5.1 与参考项目的差异

- 本项目是 Next.js 前端项目，模型放在 `app/utils/models/` 目录
- 参考项目是独立后端，模型放在 `server/src/models/` 目录
- 本项目不需要 AI 作品相关模型（ai-artwork、artwork-media）
- 本项目不需要管理员相关模型（admin-user）
- 本项目不需要大文件上传相关模型（big-file-record、big-file-chunk、temp-media）

### 5.2 边界情况

- **热重载问题**：Next.js 开发环境可能需要特殊处理，避免重复创建连接
- **连接超时**：配置 acquire: 30000，确保在高负载时有足够时间获取连接
- **空闲连接**：配置 idle: 10000，及时释放空闲连接

### 5.3 安全考虑

- 数据库密码通过环境变量配置，不要硬编码
- `.env` 文件必须添加到 `.gitignore`
- `logs/` 目录必须添加到 `.gitignore`
