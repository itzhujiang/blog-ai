## 技术要点

### 技术栈约束

根据技术方案文档，本项目必须使用以下技术栈：

- **前端框架**：Next.js 16.0.1 (App Router) + React 19.2.0
- **样式方案**：Tailwind CSS v4
- **数据库**：PostgreSQL 14+
- **ORM 工具**：Sequelize 6.x
- **内容格式**：MDX 3.x
- **TypeScript**：5.x
- **图片优化**：next/image 组件
- **HTTP 客户端**：Axios 1.x

### 涉及的主要模块

- **文章模块**：文章列表、详情、分类筛选、搜索、阅读量统计
- **评论模块**：评论列表（支持嵌套）、发表评论、评论审核、评论点赞
- **搜索模块**：PostgreSQL 全文搜索、搜索结果展示、搜索日志记录
- **用户模块**：关于我页面、社交媒体链接

### 渲染策略

根据技术方案文档，采用混合渲染策略：

- **ISR（文章列表、文章详情）**：
  - revalidate: 3600 秒（1小时）
  - 配合 On-Demand Revalidation

- **CSR（统计信息、评论区）**：
  - 阅读量、评论数实时获取
  - 评论列表客户端加载

- **SSG（关于我页面）**：
  - 构建时生成

### 数据库连接策略

根据技术方案文档，使用单例模式 + 连接池：

```typescript
pool: {
  max: 3,        // 最大连接数（2G内存限制）
  min: 0,
  idle: 10000,
  acquire: 30000,
}
```

## 备注

1. **开发顺序**：严格按照步骤序号顺序开发，确保依赖关系正确
2. **代码规范**：遵循 CLAUDE.md 中的代码规范和 Tailwind CSS 专业使用规范
3. **技术栈约束**：所有代码必须使用技术方案文档中指定的技术栈
4. **测试要求**：每个步骤完成后需要进行功能测试
5. **性能目标**：
   - 首屏加载时间 < 3秒
   - 文章详情页加载时间 < 2秒
6. **安全考虑**：
   - 使用 Sequelize 参数化查询防止 SQL 注入
   - React 自动转义防止 XSS
   - 评论内容严格过滤
7. **文件存储**：
   - Markdown 文件存储在 `/content/articles/`
   - 图片资源存储在 `/public/images/`
8. **API 接口**：使用 Next.js API Routes，无需独立后端服务
9. **目录结构**：采用 Next.js 官方推荐的根目录结构（无 src/）
