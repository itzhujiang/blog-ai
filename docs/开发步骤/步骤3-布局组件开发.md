## 二、需求说明

### 2.1 功能要求

从 PRD 文档中提取与本步骤相关的功能需求：

- 清晰的主导航菜单（首页、关于、文章、AI作品展示）
- 搜索入口（头部搜索框）
- 博客 Logo 和名称展示
- 页脚包含版权信息、社交媒体链接、快捷导航链接
- 支持亮色/暗色模式切换

### 2.2 UI 设计要求

根据 UI 设计图（首页.html）提取的布局要求：

**Header 组件**：
- 左侧：Logo 图标 + 博客名称「暖木博客」
- 中间：导航链接（首页、关于、文章、AI作品展示）- 仅桌面端显示
- 右侧：搜索输入框（圆角、带搜索图标）
- 底部边框：`border-primary/30`
- 响应式：移动端隐藏导航链接

**Footer 组件**：
- 两栏布局（桌面端）/ 单栏布局（移动端）
- 左栏：Logo + 博客名称 + 社交媒体图标（Facebook、Twitter、Instagram）
- 右栏：快捷链接（关于、文章、隐私政策）
- 底部：版权信息「© 2024 暖木博客. 版权所有.」
- 顶部边框：`border-primary/30`

**整体布局**：
- 最大宽度：`max-w-5xl`
- 水平内边距：`px-6 sm:px-8`
- 内容居中显示

### 2.3 业务规则

- 导航链接需要高亮当前页面
- 搜索框点击后跳转到搜索页面或触发搜索
- 社交媒体链接在新窗口打开
- 布局组件需要支持服务端渲染（SSR）

## 三、技术实现指引

### 3.1 技术栈约束

根据技术方案文档，本步骤必须使用以下技术栈：

- **前端框架**：Next.js 16.0.1 (App Router) + React 19.2.0
- **样式方案**：Tailwind CSS v4
- **图标方案**：使用 SVG 内联图标（参考 UI 设计图）
- **路由**：Next.js App Router（`next/link`）

### 3.2 组件设计

#### Header 组件

```typescript
// src/components/layout/Header.tsx
interface HeaderProps {
  className?: string;
}
```

**实现要点**：
- 使用 `next/link` 实现导航链接
- 使用 `usePathname` 获取当前路径，实现导航高亮
- 搜索框使用已开发的 `Input` 组件
- Logo 使用 SVG 内联图标
- 响应式设计：`md:flex` 控制导航链接显示

#### Footer 组件

```typescript
// src/components/layout/Footer.tsx
interface FooterProps {
  className?: string;
}
```

**实现要点**：
- 社交媒体图标使用 SVG 内联
- 链接使用 `next/link`
- 响应式布局：`md:grid-cols-2`

#### Navigation 组件

```typescript
// src/components/layout/Navigation.tsx
interface NavigationProps {
  className?: string;
}

interface NavItem {
  label: string;
  href: string;
}
```

**实现要点**：
- 导航项配置化，便于维护
- 当前页面高亮样式
- 支持移动端菜单（可选，后续扩展）

### 3.3 导航配置

### 3.4 根布局更新

更新 `src/app/layout.tsx`：

```typescript

  return (
    <html lang="zh">
      <body>
        <div className="relative flex min-h-screen w-full flex-col">

            <div className="layout-content-container flex w-full max-w-5xl flex-col px-6 sm:px-8">

```

### 3.5 样式规范

根据 UI 设计图和 globals.css 中的主题配置：

## 五、注意事项

### 5.1 边界情况

- **长博客名称**：确保名称不会溢出，必要时截断
- **导航项过多**：移动端需要考虑汉堡菜单（可后续扩展）
- **搜索框为空**：搜索框需要有占位符提示

### 5.2 异常处理

- **路由不存在**：导航到不存在的页面时，Next.js 会自动处理 404
- **图标加载失败**：使用内联 SVG 避免外部资源加载问题

### 5.3 兼容性

- **浏览器支持**：Chrome、Firefox、Safari、Edge 最新版本
- **设备支持**：桌面端（1920x1080+）优先，移动端基本适配

### 5.4 性能考虑

- Header 和 Footer 是静态组件，不需要客户端状态
- 使用 `next/link` 实现预加载和客户端导航
- 避免在布局组件中使用 `'use client'`（除非必要）
