## 一、步骤目标

开发博客系统文章详情页，包括面包屑导航、文章头图、文章元信息、Markdown 内容渲染（含代码高亮）、文章底部分类标签和社交分享。文章详情页采用 ISR 策略，通过 `[slug]` 动态路由访问。

**本步骤不包含评论系统**（评论系统在步骤9中实现）。

## 二、需求说明

### 2.1 功能要求

- 面包屑导航（首页 > 文章 > 分类 > 文章标题）
- 文章头图展示（aspect-video，圆角边框）
- 文章元信息（发布日期、作者、分类、评论数）
- Markdown 内容渲染（段落、标题、图片、引用、代码块）
- 代码块语法高亮 + 复制按钮
- 文章底部分类标签和社交分享链接
- 回到顶部按钮
- 动态 SEO 元数据（title、description）

### 2.2 UI 设计要求

根据 UI 设计图（文章详情页.html）提取的布局要求：

**面包屑导航**：
- 位置：文章内容上方，`mb-6`
- 样式：`text-sm text-text-light/80`
- 分隔符：Material Symbols `chevron_right` 图标
- 链接悬停：`hover:text-cta-light`
- 当前页（文章标题）：不可点击，`truncate` 截断

**文章头图**：
- 容器：`aspect-video w-full overflow-hidden rounded-xl shadow-natural`
- 使用 `next/image` 组件，`fill` 模式 + `object-cover`

**文章标题和元信息**：
- 标题：`text-4xl sm:text-5xl font-extrabold text-[#5a472b] dark:text-text-dark`，居中
- 元信息：`flex flex-wrap items-center justify-center gap-x-4 gap-y-2 text-sm`
- 图标：Material Symbols（`calendar_month`、`person`、`folder`、`mode_comment`）
- 分类名可点击，链接到 `/articles?category={slug}`

**文章内容区域**：
- 容器：`mx-auto max-w-[800px]`
- 排版：`prose prose-lg max-w-none leading-loose`
- 文字颜色：`text-[#5a472b] dark:text-text-dark/90`
- 标题颜色：`prose-headings:text-[#5a472b] dark:prose-headings:text-text-dark`
- 链接颜色：`prose-a:text-cta-light dark:prose-a:text-cta-dark`
- 图片：`rounded-lg shadow-sm hover:shadow-natural-hover`
- 代码块：浅色背景 + 复制按钮 + 语法高亮

**文章底部**：
- 分隔线：`border-t border-primary/20 pt-8 mt-12`
- 分类标签：`rounded-full bg-primary/20 px-3 py-1 text-sm`
- 分享按钮：Facebook、Twitter 图标，悬停变品牌色

**回到顶部按钮**：
- 位置：`fixed bottom-8 right-8 z-40`
- 样式：`h-12 w-12 rounded-full bg-primary/80 text-white shadow-lg`
- 图标：Material Symbols `arrow_upward`
- 悬停：`hover:bg-primary hover:shadow-xl`

### 2.3 业务规则

- 通过 `slug` 查询文章，仅显示 `status: 'published'` 的文章
- 文章不存在或未发布时返回 404
- Markdown 文件通过 `filePath` 字段从后端服务获取
- 评论数通过 SQL 子查询获取（仅 `approved` 状态）
- ISR 策略：`revalidate: 3600`
- 动态生成 `<title>` 和 `<meta description>`

## 三、技术实现指引

### 3.1 技术栈约束

根据技术方案文档，本步骤必须使用以下技术栈：

- **前端框架**：Next.js 16.0.1 (App Router) + React 19.2.0
- **样式方案**：Tailwind CSS v4
- **数据库 ORM**：Sequelize 6.x
- **图片优化**：next/image 组件
- **渲染策略**：ISR（revalidate: 3600）
- **Markdown 渲染**：react-markdown + remark-gfm（需新增依赖）
- **代码高亮**：rehype-highlight + highlight.js（需新增依赖）
- **HTTP 客户端**：Axios 1.x（获取 Markdown 文件内容）

> **新增依赖说明**：技术方案文档指定使用 MDX，但考虑到文章内容存储为纯 Markdown 文件（通过 filePath 从后端获取），使用 `react-markdown` 更为轻量和直接。如需 MDX 支持可在后续迭代中升级。

### 3.5 Markdown 文件获取

```typescript
import axios from 'axios';
import { getArticleFileUrl } from '@/utils/file-url';

async function getMarkdownContent(filePath: string): Promise<string> {
  try {
    const url = getArticleFileUrl(filePath);
    const response = await axios.get(url, { responseType: 'text' });
    return response.data;
  } catch (error) {
    console.error('获取 Markdown 文件失败:', error);
    return '';
  }
}
```

### 3.6 数据流转

```
URL /articles/[slug]
  → 服务端组件解析 slug 参数
  → Sequelize 查询文章元数据（include 分类、媒体）
  → Axios 获取 Markdown 文件内容
  → 数据序列化（BIGINT 转换、URL 处理）
  → 传递给子组件
  → ArticleContent 客户端渲染 Markdown
  → ISR 缓存
```

## 五、注意事项

### 5.1 边界情况

- **文章不存在**：slug 无效或文章未发布，调用 `notFound()` 返回 404
- **Markdown 文件获取失败**：显示空内容或友好提示
- **无头图**：显示占位区域或隐藏头图区域
- **无分类**：面包屑中省略分类层级
- **长标题**：面包屑中使用 `truncate` 截断
- **Markdown 中的图片**：需要处理相对路径转绝对路径

### 5.2 异常处理

- **数据库查询失败**：记录错误日志，返回 404
- **Markdown 文件请求超时**：设置 Axios 超时（10秒），失败时显示空内容
- **代码高亮失败**：降级为纯文本显示

### 5.3 兼容性

- **浏览器支持**：Chrome、Firefox、Safari、Edge 最新版本
- **设备支持**：桌面端优先，移动端基本适配
- **Clipboard API**：复制按钮需要 HTTPS 或 localhost 环境

### 5.4 性能考虑

- 文章详情页使用 ISR 缓存，减少数据库查询和 Markdown 解析
- 图片使用 `next/image` 自动优化和懒加载
- 代码高亮 CSS 按需引入，避免加载全部语言包
- `react-markdown` 在客户端渲染，不影响首屏 HTML 生成
- 回到顶部按钮使用 `useEffect` 监听滚动，添加节流处理
