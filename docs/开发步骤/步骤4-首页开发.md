## 二、需求说明

### 2.1 功能要求

从 PRD 文档中提取与首页相关的功能需求：

- 最新文章列表（图文并茂展示，包含缩略图、标题、摘要、发布时间）
- 分类导航（技术学习、生活故事、AI创作）
- 搜索入口（已在 Header 中实现）
- 个人简介简要信息

### 2.2 UI 设计要求

根据 UI 设计图（首页.html）提取的布局要求：

**Hero Section（个人简介区域）**：
- 左侧：博主头像（圆形，`size-48`，带阴影）
- 右侧：欢迎标题 + 简介文字 + CTA 按钮
- 响应式：移动端垂直排列，桌面端水平排列
- 内边距：`py-16 sm:py-24`

**最新文章区域**：
- 标题：「最新文章」居中显示
- 文章卡片：3 列网格布局（响应式：1/2/3 列）
- 卡片内容：缩略图（16:9）、标题、摘要、发布日期
- 卡片样式：边框、阴影、悬停效果

**分类导航区域**：
- 标题：「文章分类」居中显示
- 分类按钮：圆角胶囊样式，水平排列
- 悬停效果：背景色变化

**AI 艺术画廊预览**：
- 标题：「AI艺术画廊」居中显示
- 横向滚动画廊：snap 滚动效果
- 图片样式：正方形，边框，阴影

### 2.3 业务规则

- 首页显示最新 6 篇已发布文章
- 文章按发布时间倒序排列
- 分类点击后跳转到文章列表页（带分类筛选）
- 「阅读我的故事」按钮跳转到关于我页面
- 首页使用 ISR 策略，revalidate: 3600（1小时）

### 3.3 数据获取

首页使用 ISR 策略获取数据：

```typescript
// app/page.tsx
export const revalidate = 3600; // 1小时重新验证

async function getLatestArticles() {
  // 使用 Sequelize 查询最新 6 篇文章
  const articles = await Article.findAll({
    where: { status: 'published' },
    order: [['publishedAt', 'DESC']],
    limit: 6,
    include: [
      {
        model: ArticleMedia,
        where: { usageType: 'thumbnail' },
        include: [MediaFile],
        required: false,
      },
    ],
  });
  return articles;
}

async function getCategories() {
  // 使用 Sequelize 查询所有分类
  const categories = await Category.findAll({
    order: [['name', 'ASC']],
  });
  return categories;
}
```

### 3.4 数据流转

```
数据库 → Sequelize 查询 → 服务端组件 → 子组件 Props → 渲染 HTML → ISR 缓存
```

## 五、注意事项

### 5.1 边界情况

- **无文章数据**：显示「暂无文章」提示
- **无分类数据**：隐藏分类导航区域
- **图片加载失败**：显示占位图或默认图片
- **长标题截断**：使用 `line-clamp` 限制行数

### 5.2 异常处理

- **数据库查询失败**：记录错误日志，显示友好错误提示
- **图片 URL 无效**：使用默认占位图

### 5.3 兼容性

- **浏览器支持**：Chrome、Firefox、Safari、Edge 最新版本
- **设备支持**：桌面端（1920x1080+）优先，移动端基本适配

### 5.4 性能考虑

- 首页是静态组件，使用 ISR 缓存
- 图片使用 `next/image` 自动优化
- 避免在首页使用 `'use client'`（除非必要）
- 文章摘要限制长度，减少数据传输
