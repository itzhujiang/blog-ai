## 一、测试概述

### 1.1 测试范围

本测试用例覆盖个人博客系统的以下功能模块（不包括 AI 展示相关功能）：

1. **内容展示模块**
   - 首页展示
   - 文章列表页面
   - 文章详情页面
   - 分类浏览功能

2. **分类系统**
   - 分类展示
   - 分类筛选
   - 多分类关联

3. **互动功能**
   - 评论系统（嵌套回复、审核、点赞）
   - 搜索功能
   - 分享功能

4. **个人页面**
   - 关于我页面

### 1.2 测试目标

- 验证所有核心功能符合 PRD 需求规格
- 确保用户交互流程顺畅
- 验证边界条件和异常情况的处理
- 确保 UI 展示符合设计规范
- 验证性能指标达到验收标准

### 1.3 测试环境

| 环境项 | 要求 |
|-------|-----|
| 平台   | Windows / macOS / Linux |
| 浏览器 | Chrome 最新版、Firefox 最新版、Safari 最新版、Edge 最新版 |
| 设备   | 桌面端 (1920x1080+) |
| 网络   | 稳定网络连接 |
| 数据库 | PostgreSQL |

### 1.4 前置条件

- 系统已部署并可访问
- 数据库已初始化并包含测试数据
- 测试数据包括：至少 10 篇文章、3 个分类、若干评论
