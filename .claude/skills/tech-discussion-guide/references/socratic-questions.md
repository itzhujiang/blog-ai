# 苏格拉底式提问框架

## 提问原则

1. **开放式问题**：避免是/否问题，鼓励深入思考
2. **逐层深入**：从宏观到微观，从需求到实现
3. **权衡思考**：引导用户思考不同选择的利弊
4. **场景化**：用具体场景帮助用户理解抽象概念
5. **挑战假设**：温和地质疑用户的预设，促进反思

## 前端技术栈探讨

### 框架选择层面

**初始问题**：
- 你的团队对哪些前端框架最熟悉？
- 项目的主要用户交互模式是什么？（内容展示为主 vs 复杂交互）
- 你预期的页面数量和复杂度如何？

**深入问题**：
- 如果选择 React，你如何看待其生态系统的复杂性？
- 如果选择 Vue，你如何评估其在大型项目中的表现？
- 你是否考虑过框架的学习曲线对团队的影响？

### 元框架选择层面

**初始问题**：
- 你的内容更新频率如何？（静态内容 vs 动态内容）
- SEO 对你的项目有多重要？
- 你是否需要服务端渲染？为什么？

**深入问题**：
- Next.js 的 App Router 和 Pages Router，你了解它们的区别吗？
- 你如何看待 SSG、SSR、ISR 这些渲染策略的权衡？
- 如果用户量增长 10 倍，你的渲染策略是否需要调整？

### 样式方案层面

**初始问题**：
- 你的设计系统有多复杂？
- 团队对 CSS 的掌握程度如何？
- 你是否需要主题切换功能？

**深入问题**：
- Tailwind CSS 的原子化 CSS 方法，你如何看待其可维护性？
- 如果选择 CSS-in-JS，你如何处理服务端渲染的性能问题？
- 你的样式方案是否支持未来的设计系统演进？

## 后端技术栈探讨

### API 架构层面

**初始问题**：
- 你的前后端是否需要分离？
- API 的主要消费者是谁？（Web 前端 / 移动端 / 第三方）
- 你的数据查询模式是简单还是复杂？

**深入问题**：
- REST API 的简单性和 GraphQL 的灵活性，你如何权衡？
- 如果选择 tRPC，你如何看待其类型安全的优势和生态限制？
- 你的 API 是否需要版本管理？如何规划？

### 服务端渲染策略

**初始问题**：
- 哪些页面需要 SEO 优化？
- 哪些页面需要实时数据？
- 你的服务器资源预算如何？

**深入问题**：
- SSR 的首屏性能优势和服务器成本，你如何平衡？
- ISR 的缓存策略是否适合你的内容更新频率？
- 如果页面访问量激增，你的渲染策略是否会成为瓶颈？

### 认证方案层面

**初始问题**：
- 你的项目是否需要用户认证？
- 用户规模预期是多少？
- 是否需要第三方登录？

**深入问题**：
- Session 和 JWT 的权衡，你如何选择？
- 如果使用 JWT，你如何处理 token 刷新和撤销？
- 你的认证方案是否考虑了安全性和用户体验的平衡？

## 数据库和存储探讨

### 数据库选择层面

**初始问题**：
- 你的数据结构是关系型还是文档型？
- 预期的数据量级是多少？
- 是否需要复杂的关联查询？

**深入问题**：
- PostgreSQL 的强大功能和 MySQL 的简单性，你如何选择？
- 如果选择 NoSQL，你如何处理数据一致性问题？
- 你的数据库选择是否考虑了未来的扩展性？

### ORM/查询工具层面

**初始问题**：
- 团队对 SQL 的熟悉程度如何？
- 是否需要类型安全的数据库查询？
- 数据库迁移的频率如何？

**深入问题**：
- Prisma 的类型安全和性能开销，你如何权衡？
- 如果选择 Drizzle，你如何看待其轻量级的优势？
- 你的 ORM 选择是否支持复杂查询的优化？

### 文件存储方案

**初始问题**：
- 你需要存储哪些类型的文件？
- 预期的文件存储量是多少？
- 是否需要 CDN 加速？

**深入问题**：
- 本地存储和云存储的成本和便利性，你如何选择？
- 如果使用云存储，你如何处理文件访问权限？
- 你的文件存储方案是否考虑了备份和灾难恢复？

## 性能和优化探讨

### 图片优化层面

**初始问题**：
- 你的项目中图片占比有多大？
- 是否需要响应式图片？
- 用户的网络环境如何？

**深入问题**：
- Next.js Image 组件的自动优化和手动优化，你如何选择？
- 如果使用 CDN，你如何配置图片缓存策略？
- 你的图片优化方案是否考虑了移动端的流量成本？

### 缓存策略层面

**初始问题**：
- 哪些数据适合缓存？
- 缓存的失效策略是什么？
- 是否需要分布式缓存？

**深入问题**：
- 浏览器缓存、CDN 缓存、服务端缓存，你如何协调？
- 如果缓存失效，你如何保证数据一致性？
- 你的缓存策略是否考虑了缓存穿透和缓存雪崩？

### CDN 使用层面

**初始问题**：
- 你的用户地理分布如何？
- 静态资源的大小和数量如何？
- 预算是否支持 CDN 服务？

**深入问题**：
- 免费 CDN 和付费 CDN 的性能差异，你如何评估？
- 如果使用 CDN，你如何处理缓存更新？
- 你的 CDN 策略是否考虑了国内外访问的差异？

## 提问技巧

### 引导性提问
- "你提到 X，能否详细说明为什么选择它？"
- "如果 Y 情况发生，你的方案会如何应对？"
- "你考虑过 Z 方案吗？它与你的选择有什么区别？"

### 挑战性提问
- "这个选择的最大风险是什么？"
- "如果项目规模扩大 10 倍，这个方案还适用吗？"
- "有没有更简单的方案可以达到同样的目标？"

### 总结性提问
- "综合考虑，你认为哪个方案最适合你的项目？"
- "这些技术选择之间是否存在冲突？"
- "你对最终的技术栈有信心吗？为什么？"
